# 內湖國小教師晨會資訊站

單一正式網站專案，由 GitHub 管理版本、Netlify 自動部署。

## 部署
- Production branch: `main`
- Publish directory: repository root (`.`)
- Entry point: `index.html`

## 每週更新原則
固定區塊順序：
1. 各處室摘要與原始文件
2. 本週先做這些
3. 截止日雷達
4. 附件快速入口
5. 歷次教師晨會
6. 教師常用入口

更新時直接替換同一個 `index.html`，不要建立新網站或新 repo。
所有 Google Drive 按鈕需使用當週共用雲端硬碟的正確連結。
